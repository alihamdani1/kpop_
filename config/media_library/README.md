# Media Library Convention

Déposez ici les photos des groupes sous la structure suivante :
- Déposer directement les fichiers images (.jpg, .png, .webp) dans le dossier du groupe.
- Visé : ~15 à 30 photos par groupe à terme (aucun minimum pour démarrer).
- `tags.yaml` (optionnel) : Peut être ajouté dans chaque dossier pour affiner par thème/angle si besoin.

## `_generic/` — sujets transverses

Sert uniquement quand le sujet n'est pas rattaché à un groupe précis (ex. `group_name` =
"industrie K-pop") — jamais utilisé si un dossier de groupe existe déjà.

- `industrie/` — coulisses d'agence, contrats, conférences de presse.
- `charts_records/` — classements, certifications, streaming.
- `france/` — salles, concerts, ambiance K-pop en France.
- `fandom/` — culture de fans générique (lightsticks, foule, rituels).
- Racine de `_generic/` — repli si aucune des 4 catégories ci-dessus ne correspond.
